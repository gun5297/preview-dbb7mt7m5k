날짜 표기 줄이기

목록 날짜를 mm/dd hh:mm(다른 해는 yy/mm/dd), 초 생략, 주문 계열 목록의 일시는 날짜 · 시각 칸으로 나눔

화면

모든 목록(표)의 날짜 · 일시 컬럼

동작
  • 올해 날짜는 'mm / dd | hh:mm', 다른 해는 'yy / mm / dd | hh:mm'로 표기하고 초는 뺀다
  • 주문 계열 · 당첨 · 보더 · 포장 · 배송 목록의 일시 컬럼은 헤더 하나 아래 본문만 날짜 칸 | 시각 칸으로 나눠 각각 가운데 정렬
  • 그 밖의 목록(이벤트 · FAQ · 메시지 · 시스템 등)은 한 칸에 'mm / dd | hh:mm'
규칙

'올해'는 오늘 날짜 기준, '미정'은 그대로 표기, 상세 화면의 날짜는 바꾸지 않는다

동작

송장 번호(필수) + EMS PDF(선택, 국내는 번호만), 단일 송장 카드는 박스별 송장으로 대체

화면

배송 처리 ① 송장 등록, 배송 처리 상세 오른쪽

동작
  • 번호 입력 + PDF 첨부(끌어다 놓으면 파일명의 번호를 자동 입력)
  • 복사 · 출력 · 수정 · 삭제, 등록 · 출력 일시 표시
  • 상세 오른쪽의 단일 '송장 번호' 카드는 없앤다 — 송장은 박스마다
규칙
  • EMS 번호 형식(영문 2 · 숫자 9 · 영문 2) 확인, 첨부는 PDF만
  • PDF를 바꾸면 출력 일시가 지워져 다시 출력해야 발송할 수 있다
  • 배송비를 안내한 뒤에는 송장 수정에 사유가 필요하고 삭제할 수 없다, 발송한 박스는 잠금
